## 📖 Overview

BonaForge is a full-stack application developed to help
manage the complete client acquisition and business delivery
process from a centralized dashboard.

The platform brings together business prospecting, research,
customer relationship management, proposals, quotations,
project management, invoicing, payments, and analytics.

BonaForge was designed to reduce scattered business information
and improve the organization of daily operations.

## 🏗️ System Architecture

BonaForge follows a client-server architecture.

```text
                BONAFORGE
                    |
             React Frontend
                    |
                  Axios
                    |
                REST API
                    |
             Express Backend
                    |
         Authentication & Services
                    |
              MongoDB Atlas
```

The frontend communicates with the backend through REST APIs.

The backend handles authentication, application logic,
database operations, and business workflows.

MongoDB stores the application's persistent data.

## ⚙️ Local Development

### Prerequisites

- Node.js
- npm
- MongoDB connection
- Git

### Clone Repository

```bash
git clone https://github.com/lilbonaf-prog/BonaForge.git
cd BonaForge
```

### Backend Setup

```bash
cd server
npm install
```

Create a local `.env` file using the
provided `.env.example` as a reference.

Configure your own environment variables.

### Frontend Setup

Open another terminal:

```bash
cd client
npm install
npm run dev
```

The frontend uses Vite for development.

The backend development command should be run according
to the scripts defined in `server/package.json`.
